## Nmap

### Nmap Network Scanning

[Nmap Network Scanning — Official Nmap Project Guide](https://nmap.org/book/toc.html)

**Nmap Network Scanning** is the official guide to the Nmap Security Scanner, written by Gordon “Fyodor” Lyon, the original author of Nmap. It provides an in-depth reference for understanding Nmap and its application to network discovery, security auditing, and penetration testing.

The book covers the complete Nmap workflow, including **host discovery, [[03-Network-Pentesting/Port-Scanning|port scanning]], service and version detection, operating system detection, [[03-Network-Pentesting/Network-Enumeration|network enumeration]], the Nmap Scripting Engine (NSE), firewall and IDS evasion, performance optimisation, and scan output**.

It is particularly useful when studying [[10-Tools/Nmap|Nmap]] beyond individual commands, as it explains the underlying behaviour of different scanning techniques and how Nmap interprets responses from target systems. It can therefore be used as a technical reference alongside practical work involving [[03-Network-Pentesting/Service-Enumeration|service enumeration]] and network reconnaissance.

### Nmap Official Website

[Nmap — Official Website](https://nmap.org/)

The official Nmap website provides access to the **Nmap Security Scanner**, official documentation, downloads, reference material, and information about the Nmap project. It is the primary source for authoritative information about Nmap and its available features.
